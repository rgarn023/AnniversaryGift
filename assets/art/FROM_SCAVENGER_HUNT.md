# Scavenger hunt artwork needed

This app should reuse the chest and scroll artwork from the Boston Pokémon GO City Safari scavenger hunt app.

Those assets were **not found** in:

- this repository
- `rgarn023/PostcardPact`
- `rgarn023/JimothyPet`
- Play Store package guesses under `com.charoitegames.*`

## How to provide them

Copy the scavenger hunt layered chest/scroll images into:

```text
assets/art/chest/     # chest_base, chest_lid, chest_lock, chest_trim, etc.
assets/art/scroll/    # scroll_parchment, rollers, scroll_mini, etc.
```

Or share the scavenger hunt GitHub repo / zip / APK that contains them, and they will be imported here.

Preferred filenames (PNG with transparency):

- `chest_base.png`, `chest_lid.png`, `chest_lock.png`, `chest_trim.png`
- `chest_hinges.png`, `chest_interior.png`, `chest_glow.png`, `chest_shadow.png`
- `scroll_parchment.png`, `scroll_top_roller.png`, `scroll_bottom_roller.png`
- `scroll_mini.png`, `scroll_mini_unread.png`
